# Technical constraints

- Use semantic HTML for structure.
- Use CSS for styling; keep exactly one stylesheet in `css/`.
- Use Vanilla JavaScript only; keep exactly one JavaScript file in `js/`.
- Do not add frameworks such as React or Vue.
- Do not require a backend server.
- Store user data on the client with the browser Local Storage API.
- Support modern Chrome, Firefox, Edge, and Safari.
- Keep startup fast and interactions responsive.
- No test framework or test setup is required.
- External quick links must use HTTP or HTTPS and open with `rel="noopener noreferrer"`.
